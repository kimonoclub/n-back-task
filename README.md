# N-Back Game Demo Project

## Overview
The N-Back Game is a challenging cognitive task designed to test and improve working memory and cognitive flexibility. In this game, players must remember a sequence of stimuli presented over time, responding whenever the current stimulus matches the one from 'n' steps earlier in the sequence. The game can be adjusted for different levels of difficulty by changing the value of 'n'.

## Features
- **Adjustable Difficulty**: Users can select the n-value (1, 2, 3, etc.) to increase or decrease the level of challenge.
- **Real-time Feedback**: Players receive immediate feedback on their responses to help gauge performance.
- **Score Tracking**: The game keeps track of the player's score and displays it at the end of each session.
- **User-friendly Interface**: Designed to be intuitive and easy to navigate for all ages.

## Getting Started
### Prerequisites
- A modern web browser (Chrome, Firefox, Safari)
- Internet connection (if online version)

### Installation
To run the N-Back Game locally:
1. Clone the repository:
   ```bash
   git clone https://github.com/kimonoclub/n-back-task.git
   ```
2. Navigate to the project directory:
   ```bash
   cd n-back-task
   ```
3. Open the HTML file in your browser

## How to Play
1. Start the game by clicking the 'Start' button.
2. Observe the sequence of stimuli (letters, numbers, or colors).
3. Respond whenever you recognize a stimulus that matches the one from 'n' steps earlier.

## Conclusion
The N-Back Game is not only a fun and engaging way to test your memory but is also a useful tool for cognitive training. Challenge yourself and see how well you can improve your working memory!
